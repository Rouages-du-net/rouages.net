# Les rouages du net

Internet, l'informatique et l'IA expliqués de manière animée et didactique,
**sans masquer la vraie technologie**. Dans l'esprit de
[rouages.fr](https://rouages.fr).

- [Vision](docs/VISION.md) — principes et modules
- [Feuille de route](docs/ROADMAP.md)
- [Personnes et projets à mettre en avant](docs/PERSONNES.md)
- [Charte des sources](docs/SOURCES.md)
- [Charte graphique](docs/CHARTE.md)
- [Choix techniques et déploiement cPanel](docs/STACK.md)

## Démarrer

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # génère dist/ à envoyer sur cPanel
```
