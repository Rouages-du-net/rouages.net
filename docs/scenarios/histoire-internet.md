# Scénario — « Histoire d'internet »

*Une histoire mondiale d'internet, avec celles et ceux qu'on oublie.* Statut :
**publié** (`/modules/histoire-internet/`), relecture humaine à faire. Faits
sourcés dans [`docs/sources/internet.md`](../sources/internet.md).

## Intention

Raconter internet comme une suite d'idées, de câbles et de conventions venues
de plusieurs pays (`VISION.md`, § 3) : une frise filtrable par région, thème et
pionnières, puis quatre idées clés (réseau de réseaux, noms, web ≠ internet,
internet ailleurs), en démontant les « premières » et les attributions uniques.

## Les étapes

| # | Étape | Animation | Contenu |
|---|---|---|---|
| 0 | Un siècle et demi de réseaux | `FriseHistoire` | 32 événements (1858-2025), filtres région (dont Amérique latine) / thème / pionnières, une source par événement |
| 1 | Un réseau de réseaux | texte | Baran, Taylor, CYCLADES (Pouzin), Cerf et Kahn, 1981, 1983 ; mythe nucléaire |
| 2 | Des noms plutôt que des numéros | texte | Feinler (NIC, HOSTS.TXT, WHOIS), DNS, RFC 920, Perlman ; mythes « mère d'internet », « Feinler a inventé le DNS » |
| 3 | Le web n'est pas internet | texte | CERN 1989-1993, Pellow, Minitel (1983-2012) |
| 4 | Internet ailleurs | texte | Kilnam Chon (SDN), Nii Quaynor, AFRINIC, M-Pesa (étude contestée), câbles sous-marins |
| ✓ | Ce qu'il faut retenir | liste | cinq points |

## Choix et limites

- La frise est lisible sans JavaScript (liste complète) ; les filtres ne font
  que masquer des éléments.
- Auteurs des RFC cités par leurs initiales, comme dans les RFC (Mockapetris,
  Postel, Reynolds).
- Non repris faute de vérification : le NPL britannique (Donald Davies) en
  détail, l'annotation « Vague but exciting », la situation actuelle
  d'AFRINIC, la citation de Herzfeld.
- Chine (Hu Qiheng, 2009), Inde (ERNET, VSNL) et Brésil (FAPESP) ajoutés le
  3 novembre 2026 ; le Mexique (ITESM, 1989) attend une source solide.
